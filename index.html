04 / AgentBrain

Three speeds of
thinking.

Not every request deserves a full reasoning loop. AgentBrain routes work to the lightest tier that can solve it, then escalates when the task demands deeper planning.

01
< 100 MS

Reflex

Deterministic actions and exact-match recipes. No LLM call when the system already knows what should happen.

Fast path
02
1–3 SEC

Instinct

A single model call for most conversational requests, with only the tools relevant to the request loaded.

Most requests
03
5–30 SEC

Deliberation

Multi-step reasoning and tool loops for complex tasks where planning, retrieval and verification matter.

Deep work
